# Gina's Coffee Quest 3.3 ☕👻

A small arcade coffee game built with HTML, CSS and JavaScript.

Collect coffee, cookies and power-ups, avoid bugs, build combos and unlock medals on your way to becoming **Gina's Lieblingsadmin**. 💎

## Features

* ☕ Coffee collection system
* 🍪 Cookie bonus items
* ⚡ Power-Ups (Turbo, Protection, Double Score)
* 🏆 Highscore tracking
* 💎 Medal system & persistent achievement overview
* 🎯 Near-Miss bonus
* 📈 Combo scoring
* 📶 Three-stage difficulty curve
* 🐛 Standard, sprinter and hunter bugs
* 🏅 Live medal progress
* 📊 Detailed end-of-game statistics
* 🎵 Music support
* 📱 Desktop and mobile friendly

## Controls

### Desktop

* Arrow Keys or WASD = Move
* P = Pause

### Mobile

* Virtual joystick = Move
